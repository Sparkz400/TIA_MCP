# Protected library fixture

`TiaMcpProtectedPlain.scl` is a minimal original FB used to create a global-library master copy from a know-how
protected block. `scripts/qualify_library_protected.py` imports it into an owned scratch, then
`scripts/native/LibraryUnitSeeder protect` protects it (and, separately, the in-work test instance of the
`type-lifecycle` FB type) with a random password that is never stored. The consumer's Main and instance DBs are
generated by the runner from the routes that produced content. Run with `--run-native`, immutable `--host`/`--worker`
paths, the registered `--unit-seeder` and a short `--artifacts` directory.
