`scripts/probe_followups.py` ran on this workstation (TIA Portal V21) against one owned scratch it created with
`tia_create_scratch`. No other project was opened. These are single runs, not curated catalog evidence; the catalog
entries stay unverified.

| Check | Result |
| --- | --- |

The block stayed inconsistent (unchanged) |
| `project_close` with unsaved edits | Refused (`UnsavedProject`); with `discardUnsaved: true` closed without saving |

| Worker start with the new flag field | A first build set the flag on `OpennessSession` inside `Main`, which loaded the Siemens assemblies before the resolver and crashed every worker start (`FileNotFoundException`); the flag now lives on `Program` |

Reports: `artifacts/pf6/report.json` (LAD routes), `artifacts/pf8/report.json` (final run) in the follow-up worktree.

## Graphical recovery

(`ExportAsDocuments`), so no Openness gap is recorded. What stays open: no route writes an edited SIMATIC SD document
back, so the repair is still an explicit tag or block change.
