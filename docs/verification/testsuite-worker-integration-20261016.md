## Wiring and evidence boundaries

- [Host transport](../../src/TiaMcp.Core/TestSuite/TestSuiteWorkerAdapter.cs) sends the exact operation and a verified original-definition bundle to one owning worker. Every subsequent stage rereads the authoritative journal after its intent is flushed. Exact lease, operation and plan identity are carried across observations, checkpoint, dispatch, verification, recovery and reconciliation. It never starts a second worker to replace a failed connection.
- [Worker session](../../src/TiaMcp.TestSuite.V21/StyleWorkerSession.cs) owns exclusive access across the two observations and one dispatch. Other worker operations, including watch/shared mutation, project switching and detach, are excluded while the lease is held. Failed stages poison the session; unknown calls and failed lease release cannot be replayed or later reported successful.
- [Native binding](../../src/TiaMcp.Openness.V21/OpennessSession.TestSuite.cs) connects actual scratch ownership/offline checks, public prerequisite inspection, native archive creation, exposed engineering/definition preservation captures, compilation, save/fresh reopen, retrieval to a new destination and independent reconciliation observations. These hooks are not qualified providers: complete effective scope and current execution-license evidence remain unavailable; verification and reconciliation explicitly refuse incomplete preservation/cleanup dispositions. This increment does **not** claim a completed native recovery workflow.
- [Raw capture](../../src/TiaMcp.TestSuite.V21/StyleRawCapture.cs) flushes native result bytes before Host parsing or normalization. Interrupted message enumeration retains the observed partial tree with `collectionComplete=false` and a separate exception receipt. The Host reads the retained worker artifact by hash, preserving malformed/unknown/duplicate JSON bytes for durable failure classification. It does not reserialize a parsed result as the original capture.

The internal `testsuite_style_prerequisites` route permits read-only public scope/service observations in an exact saved, worker-owned scratch. It neither imports a definition nor calls SetScope, archive, save or Run. It inspects only advertised scope routes and keeps returned selectors as unqualified candidates. DLL/service presence leaves execution licensing unknown. No public MCP tool was added by this increment.
