# Review supplied Teamcenter metadata and local manifests

`teamcenter_observation_review(uploadRef)` compares a committed `teamcenter-observations.v1` request, up to 4 MiB. It retains exact before/after declarations of connection context, items, revisions, datasets, lock state and local source/cache copies. It never connects, authenticates, searches, downloads, opens, checks out, saves, checks in or cancels a checkout. [Schema](../../contracts/teamcenter-observations.v1.schema.json), [example request](../../fixtures/teamcenter/observations.json), [example manifest](../../fixtures/teamcenter/local-manifest.json), [full X09 plan](../plans/expansion-plans/teamcenter-gateway.md).

Upload and commit each local manifest first using the artifact-upload tools. Put its returned `upload:` reference and exact byte SHA-256 into each applicable local-copy row. Replace the example's placeholder upload reference; it is not an existing upload. Then upload/commit the comparison request and call the review tool. A comparison supports up to 16 distinct manifest upload references, each at most 1 MiB. No declared root or file path is read from the workstation.

The connection declaration includes the public server URL, instance, principal/group/role and opaque local connection ID/epoch. Server URL and instance must match exactly across phases; no aliases are repaired. URLs cannot embed credentials, queries or fragments. Connection-context changes remain in metadata comparisons. These declarations do not authenticate a producer, endpoint or session. Use public property values and diagnostic text only: passwords, session tokens and credentials are not accepted connection fields, and recognized credential property names refuse. This is not automatic redaction of arbitrary free text.

Identity uses project/global-library kind plus exact item ID, then opaque revision ID, then dataset type/name. Revision IDs are not parsed or sorted as numeric versions. Missing parent declarations remain issues. Duplicate identities or contradictory project/library dataset types refuse. `onlyBefore`, `onlyAfter` and `differentObservation` describe supplied differences, never native deletion, creation or publication outcomes. Original row order and unchanged rows remain inspectable.

Each collection declares complete/partial/unknown/denied/failed/unavailable coverage. Incomplete coverage requires a public diagnostic, and only complete/partial sections can contain rows. Dataset lock state distinguishes checked out with a declared owner, checked in, and unknown. A matching username does not prove this operation owns a checkout. Unknown versions and differing supplied cache/server versions remain explicit; no overwrite is proposed or authorized.

A `teamcenter-local-manifest.v1` document declares its exact root, coverage and relative files with byte counts and SHA-256 values. Its root must match the local-copy path. File paths must use exact portable forward-slash spelling; traversal, device names, alternate streams, case aliases and file/ancestor collisions refuse. Byte counts must be nonnegative JSON-safe integers. At most 4,096 file declarations are accepted per manifest. The original manifest bytes are copied into independent retained artifacts, rehashed and checked on reopening. **Manifest byte integrity is verified; declared file bytes, cache completeness and native content are not.**

`teamcenter_observation_page(recordId, section, offset, count)` reopens and rebuilds the report from retained request and manifests. Sections are summary/observations/changes/issues/manifests; 1..200 requested rows fit within 128 KiB. Oversized rows have an explicit omission marker and remain in the complete artifact. The receipt supplies original request, manifest and report references for `artifact_read` export. Release of the original uploads and Host restart preserve the retained report without repeating acquisition. Missing/changed evidence or a newly hashed forged report refuses.

Per capture: at most 256 items, 512 revisions, 1,024 datasets and 128 local copies; at most 64 public properties per row. Public property values preserve bounded strings, including layout whitespace, or explicit null. Reports are bounded to 64 MiB and retained storage to 512 MiB, including incomplete publication files. Partial publication cannot authorize external work.

Source authenticity, live freshness, checkout ownership, file-byte verification, native-cache verification and native execution/qualification remain false. These tools cannot settle an engineering operation journal. Native adapters, independent server outcome queries, complete file preservation and the remaining TC-03–10 workflows remain open.
