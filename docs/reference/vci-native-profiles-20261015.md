## Executable preservation review

It freezes/hashes every supplied file including unknown companions, requires the explicit primary/companion inventory, checks SimaticML block kind/name/number, and compares every requested culture/text exactly. Missing/changed/extra cultures, duplicate native cultures, unknown rich text and missing SD resources cannot pass.
