![TIA MCP — Inspect. Preview. Change. Verify.](https://raw.githubusercontent.com/Sparkz400/TIA_MCP/main/docs/assets/tia-mcp-banner.svg)

TIA MCP is a Windows [Model Context Protocol](https://modelcontextprotocol.io) server that lets an MCP client inspect and make recoverable changes to offline **TIA Portal V21** projects, with simulation through **PLCSIM Advanced V8**.

> **Pre-1.0.** Offline tooling is validated in CI; live TIA Portal and PLCSIM runtime qualification is incomplete. Use it only with offline projects, copies, scratch projects and simulators you own, never with production PLCs or plants.
